# Naches Learning Hub — Wildlife Update v31.3

This update adds five more animated wildlife visitors to the existing Living Landscape (without changing the activity catalog):

- Rabbit
- Fox
- Owl (a gentle sway rather than walking)
- Raccoon
- Black bear (very rare)

Existing squirrel, deer, elk, and coyote artwork remains. Wildlife appears automatically for about **44% of calendar dates** using a stable date-based choice; no individual animal appears on every visit. The scene's **Scene options → Wildlife preview** menu allows choosing a specific animal. Reduced-motion preferences remain respected.

## Install

Replace the root `index.html` and `activities.json` in the `jkramer-cloud.github.io` repository with the files in this folder. `activities.json` is included unchanged from the latest integrated v31.2 catalog (which has playable Bridge Builder, Playbook Tactics, Team Scorekeeper staff resource, and no Body Systems Explorer).

The Hub's `team-scorekeeper` tile links to the repository you publish separately; upload its new V2 `index.html` into that repository to see the improved Game Day screen.
