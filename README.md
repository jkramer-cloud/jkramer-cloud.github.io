## Upload to existing GitHub Hub repository
1. Open your existing `jkramer-cloud/jkramer-cloud.github.io` repository.
2. Extract this ZIP and upload/replace its **`index.html` and `activities.json` at repository root**. The Markdown files are optional documentation.
3. Commit to the published branch. Do **not** upload the separate game files to the Hub repository.
4. Create/publish the `checkers-academy` repository with the separate game package. Once Pages is live there, the new tile will launch it.

The Hub is a launcher. Games continue to live in their own repositories. New roadmap cards are ideas, not implemented games.
