4. Extract this ZIP to a temporary folder (not into the repository).
5. Copy extracted index.html, activities.json, and the complete pocket-critters folder into the repository folder.
6. Windows should prompt to replace index.html and activities.json: choose Replace.

9. Click Push origin. Wait for GitHub Pages to deploy, then hard refresh the Hub (Ctrl+Shift+R).
