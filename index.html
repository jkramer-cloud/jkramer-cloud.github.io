For teachers: using and updating this hub

Each activity opens its own existing website. The hub does not change those games or their saved progress. The grade filters are suggestions, not restrictions. To add a game, tutorial, simulation, or tool later, edit activities.json in this hub's GitHub repository. Use status: planned until the activity is ready, then change to available and add its live URL. This site is a directory, not an account system or assignment tracker.

School filtering may require your tech department to allow each destination URL, not just this hub's address.
